1方針　お金がかかる経路を、そもそも作らない

PHEREのGoogleアカウントで発行し、資産をお店に帰属させます。そして請求先アカウントは絶対にリンクしません。カード未登録のままなら課金の経路が構造的に存在しないので、キーが万一漏れても金銭的な被害はありません（最悪でも無料枠を使い切るだけ）。

2発行手順

  1. PHEREのGoogleアカウントでログインした状態で aistudio.google.com を開く
  2. 左メニューまたは右上の 「Get API key（APIキーを取得）」
  3. 「APIキーを作成」→ 新規プロジェクトのまま作成（名称例：phere-post-assistant）
  4. 表示されたキーをコピー（形式は AIza… または新形式 AQ.…）
  5. 17番HTMLへの埋め込みは設定スクリプトが自動で行う。手動なら上部の var GEMINI_KEY=''; に貼る 
    zsh ~/Desktop/claude/phere/set_gemini_key.sh
  6. 動作確認：店の花か商品の写真で1回生成。3秒前後で3案が返れば完了
  7. 配布はURL方式：公開版 skmofu.github.io/phere-post-assistant/ にキーは置かず、リンク末尾の #k=キー で受け渡す（#以降はサーバーに送信されません）。完成リンク＝Mac の link.txt。当日その場でQR（qr_17.html）を画面表示して、河野さん・中川さんの2人限定でお渡しします。キーを再発行したら link.txt と qr_17.html を作り直す
やらないこと
  • 課金アカウント／請求先のリンク
  • 有料プランへのアップグレード

4運用ルール

1お客様が写る写真は送らない
無料枠の入出力はサービス改善に利用され得るためです。花・お茶・商品・後ろ姿はOK。
2キーの保管場所
PHERE_AI/90_運用ログ/ 内のメモなど、ドライブ内限定。チャットやメールの平文で共有しない。
3漏れた・調子が悪いとき
AI Studio（またはGCPの「APIとサービス→認証情報」）から無効化 → 再発行 → 貼り替えで完結します。
4無料枠の上限
数値はモデルと時期で変わるので固定値を信じず、AI Studioのレート制限画面が正。サロン運用（週数件〜月数十件）は余裕圏です。
