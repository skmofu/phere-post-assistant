16 ／ Googleドライブ構成設計

見せるのは、
ひとつのフォルダだけ。

資料も、事前送付物も、写真の受け口も1アカウントに整理します。ただしお二人の画面に出るのは「写真ポスト」1つだけにします。

ドライブ整備用　最終更新：2026-08-13

フォルダ構成共有の設計セキュリティ移行手順
設計の狙い ①勉強会資料 ②事前送付物 ③SNS効率化の受け口 を1つのアカウントに整理しつつ、お二人に見せるのは10_写真ポストの1フォルダだけにします。見えるものが少ないほど、迷いません。

1フォルダ構成　マイドライブ直下

PHERE_AI/
├ 01_勉強会資料/本キット 00〜18 の一式マスターのみ
├ 02_事前送付/お二人へ送る最小セット（01・02・12・15）マスターのみ
├ 10_写真ポスト/唯一お二人と共有する運用フォルダ編集者で共有
│　├ サイト用/
│　├ インスタ用/
│　└ どちらでも/迷ったらここ。ショートカットの既定の保存先
├ 11_投稿済みアーカイブ/処理後に自動で移動。重複防止の台帳も兼ねる
├ 20_サイト素材/ロゴ・JOURNAL用のリサイズ済み画像・SEO文言
├ 30_インスタ運用/投稿カレンダー・キャプションのストック・実績
└ 90_運用ログ/投稿台帳・月次レポート（自動生成）

2共有の設計　迷いを最小に

1共有するのは1つだけ
お二人の個人Googleアカウントには 10_写真ポスト のみ「編集者」で共有。他は見せません。
2リンク共有はOFF
全フォルダでリンク共有を切り、特定のユーザーのみに。
3ショートカットを2台に
iPhoneの共有シートから使える「PHEREに送る」を設定（保存先＝10_写真ポスト／どちらでも）。ホーム画面にも追加すればアプリ同然です。
417番はファイルで渡さない
配布は公開URL＋キー付きリンク（Mac の link.txt）。当日その場でQR（qr_17.html）を見せて開いてもらいます。「ホーム画面に追加」でアプリ化。

3新規アカウントのセキュリティ最低ライン

  • 2段階認証をON（認証アプリ推奨）／再設定用の連絡先＝マスター
  • 認証情報は紙で保管＋マスター側に暗号化した控え。平文のチャット共有はしない
  • このアカウントを WordPress・Meta・LINE公式 の登録メールに順次そろえていく
    ——お店の資産を、お店のアカウントに帰属させるため

4移行手順　マスター・15分

  1. PHERE_AI/ 以下を上のツリーどおりに作成
  2. ①②のファイルをダウンロード → 01_勉強会資料/ と 02_事前送付/ へ格納
  3. 10_写真ポスト/ をお二人に共有（勉強会の当日でOK）
  4. ig_thumbs（実インスタの参照画像）を 30_インスタ運用/ へ
